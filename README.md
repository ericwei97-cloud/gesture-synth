# Gesture Synth

A camera-based musical instrument that lets you control chords, tone, and expression using hand gestures.

## Demo

🎥 Watch the Gesture Synth tutorial on Instagram:
https://www.instagram.com/p/DbH1BACxNCG/

## Features
- Left hand controls chord selection
- Right hand controls voicing and expression
- Optional hand-role toggle lets you swap the mapping for alternate playing setups
- Real-time hand tracking with MediaPipe
- Web Audio API synthesis

## Hand roles
By default, the left hand selects the chord and determines the mode, while the right hand handles voicing and expression. A toggle in the interface can swap the roles, which can be useful for experimenting (e.g. with a more sax-friendly setup where chord changes feel more natural on the right hand).

## Built With
- JavaScript
- MediaPipe Hand Landmarker
- Web Audio API
- Vite
